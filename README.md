# 🐍 Python 小白起飞教程（零基础友好）

面向小小白的 Python 入门学习包，包含「图文教程 + 闯关游戏」两部分，全部为单个 HTML 文件，下载后浏览器直接打开即可，无需联网、无需安装任何东西。

## 📚 内容

| 文件 | 说明 |
|------|------|
| `python入门教程.html` | 手把手图文教程：安装 → 变量 → 判断 → 循环 → 列表/字典 → 函数 → 报错自救指南，附猜数字游戏 + 小账本两个实战项目 |
| `python闯关岛.html` | 闯关学习游戏：8 关解锁制，知识卡 + 选择/猜输出/填空/找 Bug 四种题型，错题重考、三星评价、进度自动保存、毕业证书 |

## 🚀 使用方法

1. 下载 HTML 文件（或 `git clone` 本仓库）
2. 双击用浏览器打开
3. 建议学习路径：**教程通读一遍 → 闯关岛通关 → 回到教程亲手敲「猜数字」和「小账本」两个项目**

## 🎯 适合谁

- 完全零基础、从没写过代码的人
- 被大段术语劝退过、想轻松入门的人
- 想教孩子 / 学生入门编程的老师和家长

## 📖 推荐学习顺序

```
游戏通关（建立信心 + 记住语法）
   ↓
教程实战项目（真正动手写代码）
   ↓
自己改造项目（加功能，比如给账本加统计图表）
```
